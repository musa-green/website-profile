Overview

One platform. Every parameter. Every stakeholder view.

MUSA View sits at the top of the MUSA pipeline. The Integrator pushes data, Data Management warehouses it; View is where the data becomes a working environmental twin - for the operator on the shop floor, the HSE manager, the kawasan executive, and the auditor.

Every solution in the MUSA catalogue surfaces here: CEMS stack cards, SPARING outfall trends, ISPU ambient maps, carbon ledgers, GRI report drafts - all driven off the same warehouse, all reconciled to the same regulatory baseline. No swivel-chair between tools, no exported CSVs.

Where it matters, View is more than a dashboard. Dispersion models, water-balance models and emission factors are first-class objects: change an input and watch the twin recompute downstream KPIs in real time.

Technical specs

Under the hood.

Deployment Multi-tenant SaaS (managed cloud) · Single-tenant private cloud · On-premise (paired with MUSA Data Management on-prem)
Data ingestion Streaming from MUSA Integrator (MQTT, REST). Batch import for legacy CSV / Excel archives. SDI-12 and OPC-UA gateways available.
Retention Hot tier: 18 months full resolution. Warm: 5 years 5-minute roll-ups. Cold: archival ≥ 10 years (compliance copies)
Refresh rate 1-second telemetry render where the source supports it; standard refresh 30 s. Submission cadence per regulation (SISPEK / SPARING / ISPU)
Models included AERMOD-style dispersion · Water balance · GHG Scope 1/2/3 calculation engine · Energy intensity (kWh / unit output)
Integrations SISPEK · SPARING · KLHK PROPER · CDP API · Microsoft 365 · Slack · Telegram · Webhook out
Access & security SSO (SAML, OIDC) · Role-based access control · Tenant-scoped data isolation · Audit log on every read/write · TLS 1.3 in transit, AES-256 at rest
SLA 99.9% platform uptime on managed cloud. 4-hour P1 response. Quarterly compliance reconciliation included.
Browser support Latest Chrome, Edge, Safari, Firefox. Desktop-first; responsive down to tablet. Field-tech mobile app in pilot.
